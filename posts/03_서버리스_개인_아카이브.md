## Serverless & Git 기반 개인 아카이브 구조

서버 비용 0원으로 나만의 마크다운 블로그와 CMS를 구축하는 방법입니다.

### 시스템 아키텍처
1. **프론트엔드**: Vanilla HTML/Tailwind CSS를 통한 초고속 렌더링
2. **데이터 저장소**: GitHub Repo 내 `data/posts.json`
3. **서버리스 함수**: `/api/config`를 통해 Vercel 환경 변수 안전 주입
4. **인증**: SessionStorage 기반 경량 관리자 인증
